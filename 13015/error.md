## 名词解释

### 时钟周期

计算机执行一条指令的过程被分成若干步骤完成，每一步都要有相应的控制信号进行控制，计算机必须能够产生同步的时钟定时信号，即 CPU 主脉冲信号，其宽度称为时钟周期。 


### 主频

主频就是 CPU 主脉冲信号的时钟频率,是 CPU 时钟周期的倒数。

### 数据通路

通常将指令执行过程中数据所经过的路径,(2 分) 包括路径上的部件称为数据通路。 (1 分)

### 栈帧

每个过程在栈中拥有的专属栈区,用于保存过程调用的入口参数、返回地址、被保存寄存器的值、非静态局部变量等数据。

### 机器数

通常将数值数据在计算机内部编码表示的数称为机器数。(3分)机器数中只有0和1两种符号,或机器数一定是一个0/1序列。(2分)

### 重定位

重新确定代码和数据的地址,并更新指令中被引用符号地址的操作。

### 易失性存储器

在电源关闭时信息自动丢失,(3分)如主存(1分)和高速缓存(1分)都属于易失性存储器。

### 独立编址

独立编址方式对所有I/O端口单独编号，使它们成为一个与主存地址空间独立的I/O地址空间。采用该编址方式时，无法从地址码区分CPU访问的是I/O端口还是主存单元，因此指令系统中需要有专门的I/O指令表明访问的是I/O地址空间，I/O指令中地址码部分给出I/O端口号。CPU执行I/O指令时，会产生I/O读/写的总线事务，CPU通过该总线事务访问I/O端口。

### 统一编址

统一编址（也叫 “存储器映射 I/O” ）是计算机体系结构中 I/O 设备的一种编址方式，核心逻辑是： 将 I/O 设备的所有相关寄存器（如控制寄存器、数据寄存器、状态寄存器等 ）视为主存的一部分，为每个寄存器单独分配一个唯一的 “内存地址” ，并将这些地址纳入主存的地址空间中。

### 虚拟存储器

虚拟存储器是构造的一个大容量的存储系统,使得应用程序可以像使用内存一样使用辅助存储器的空间。

### 何谓虚拟存储器?其主要好处是什么?

定义：在存储管理部件（硬件）和操作系统的存储管理软件支持下，把“主存——辅存"作为一个整体，为程序员提供一个比主存大很多倍的软件编程空间，该存储空间就称为虚拟存储空间或虚拟存储器。(3分)  
好处：从整体上看，使存储系统的速度接近主存访问速度，而存储容量大，接近于辅存的容量。每位平均价格低，接近于辅存的每位平均价格。(2分)

### 动态链接

共享目标文件(共享库文件)能在可执行文件装入或运行时被动态地装入内存并自动被链接的过程,由动态链接器完成。

### 中央处理器

通常把控制部件、运算部件和各类寄存器互连组成的电路称为中央处理器。

### 进程

是一个具有一定独立功能的程序关于某个数据集合的一次运行活动。


### 指令集体系结构(ISA)

是软件和硬件之间接口的一个完整定义,定义了一台计算机可以执行的所有指令的集合,每条指令规定了计算机执行什么操作,以及所处理的操作数存放的地址空间以及操作数类型。

### 虚拟存储器

一种将主存和外存抽象结合的存储技术,通过MMU将指令中的虚拟地址转换为主存物理地址。


### 数据对齐

为避免多次访存延长指令执行时间,编译器按特定规则分配数据存储地址的方式。




## 简答题

### 简述冯·诺依曼结构的基本思想

(1)采用“存储程序”工作方式;  
(2)计算机由运算器、控制器、存储器、输入设备和输出设备五大基本部件组成;  
(3)存储器能存放数据和指令,形式上无区别但计算机能区分,控制器能自动执行指令,运算器能进行基本算术和逻辑运算,操作人员通过输入/输出设备使用计算机;  
(4)计算机内部以二进制形式表示指令和数据,每条指令由操作码和地址码两部分组成,操作码指出操作类型,地址码指出操作数的地址,由一串指令组成程序。

### 简述计算机系统基本性能指标和CPU的性能指标

计算机系统的基本性能指标包括响应时间和吞吐率。(2分,1分/个)CPU的基本性能指标包括时钟周期时钟频率或主频CPI。(3分,1分/个)

### 简述原码乘法运算过程

用原码实现乘法运算时,符号位与数值位分开计算,因此,原码乘法运算分为两步。(1分)  

①确定乘积的符号位。由两个乘数的符号异或得到。(2分)  

②计算乘积的数值位。乘积的数值部分为两个乘数的数值部分之积。(2分)

### 简述浮点数加减法的运算步骤

(1)对阶:小阶向大阶看齐,阶小的数的尾数右移,右移位数等于两个阶的差的绝对值,使两数阶码相等;  
(2)尾数加减:对阶后进行定点原码小数的加减运算,需还原隐藏位并保留附加位;  
(3)尾数规格化:结果为±1b.bb…b时右规(尾数右移一位,阶码加1),结果为±0.00…01b…b时左规(尾数左移,阶码减1,直到第一位“1”移到小数点左边);  
(4)尾数舍入处理:按IEEE 754标准的就近舍入、朝+∞方向舍入、朝-∞方向舍入或朝0方向舍入模式处理;  
(5)阶的溢出判断:若正阶超过最大允许值,发生“阶上溢”,浮点数溢出由阶上溢判断,尾数溢出可通过右规纠正。

### 简述在递归深度较深时，递归调用的时间开销和空间开销都会较大的原因

每个过程包含准备阶段和结束阶段,并在栈中新增一个栈帧,(2分)因而,每增加一次过程调用,就要增加许多条包含在准备阶段和结束阶段的额外指令,并增加一个栈帧的空间,(2分)当递归调用深度较深时,这些额外指令的执行时间开销和栈帧的空间开销就会很大,有些情况下甚至发生栈溢出。(2分)

### RISC精简指令集计算机的特点

1. 指令数目少
2. 指令格式规整，采用定长指令字方式
3. 只有Load/Store指令中的数据需要访存
4. 采用大量通用寄存器

### I/O子系统的工作过程

首先，CPU在用户态下运行用户进程，当CPU执行到系统调用封装函数对应的指令序列中的陷阱指令时，会从用户态陷入内核态；转到内核态执行后，CPU会根据陷阱指令执行时EAX寄存器中的系统调用号，选择执行相应的系统调用服务例程；在系统调用服务例程的执行过程中，可能需要调用具体设备的驱动程序；在设备驱动程序执行过程中启动外设工作，外设准备好数据或准备好接收数据后，就发出中断请求：CPU响应中断后，就调出中断服务程序执行。在中断服务程序中控制主机与设备进行具体的数据交换。

### 简述程序直接控制I/O方式的基本思想

程序直接控制I/O方式的基本工作原理是直接通过查询程序来控制主机和外设的数据交换。(3分)该方式在查询程序中通过I/O指令读出外设或其设备控制器的状态后,根据状态来控制外设和主机的数据交换。(2分)

### 简述静态链接和动态链接的差别

静态链接方式因库函数代码被合并在可执行文件中,因而会造成盘空间和主存空间的浪费;(2分)另外,静态链接方式更新困难、使用不便。(1分)动态链接方式采用共享库的动态链接方式,它具有共享性和动态性,共享性可以节省主存资源和硬盘空间,动态性保证每次加载或执行程序时所链接的共享库总是最新的。(2分)

### CPU对异常和中断的响应过程可分为三个步骤？

保护断点和程序状态、关中断、识别异常和中断事件并转相应处理程序。

### 简述全局符号解析的规则？

- 规则1:强符号不能多次定义，否则链接错误。  
- 规则2:若出现一次强符号定义和多次COMMON符号或弱符号定义，则按强符号定义为准。  
- 规则3：若同时出现COMMON符号定义和弱符号定义，则按COMMON符号定义为准。  
- 规则4：若一个COMMON符号出现多次定义。则以其中占空间最大的一个为准。因为符号表中仅记录COMMON符号的最小长度，而不会记录变量的类型，因此在链接器确定多重COMMON符号的唯一定义时，以最小长度中的最大值为准进行符号解析.能够保证满足所有同名COMMON符号的空间要求。  
- 规则5：若使用编译选项-fno-common，则不考虑COMMON符号，相当于将COMMON符号作为强符号处理。

### i386 System V ABI对struct结构体数据的规则？

①整个结构体变量的对齐方式与其中对齐方式最严格的成员相同：  
②每个成员在满足其对齐方式的前提下，取地址最小的可用位置作为成员在结构体中的偏移量。这可能导致内部插空；  
③结构体大小应为对齐边界长度的整数倍。这可能会导致尾部插空。  
前两条规则是为了保证结构体中的任意成员都能以对齐的方式访问。

### 可重定位目标文件和可执行目标文件的主要差别是什么？

可执行目标文件由链接器将若干个相互关联的可重定位目标文件组合起来而生成。可重定位文件中的代码和数据的地址是相对于起始地址0而得到的，可执行文件中代码和数据的地址则按照操作系统规定的存储器映像来确定起始地址，并且可重定位文件中代码和数据的地址将会被修改，使得它们被重定位到运行时的虚拟存储空间中相应地址处。可执行目标文件格式与可重定位目标文件格式类似，例如，这两种格式中ELF头的数据结构一样，.text节、.rodata节和.data节中除了有些重定位地址不同以外，大部分都类似。相比于ELF可重定位目标文件，可执行目标文件的不同之处表现在以下几个方面：  
①ELF头中字段e_entry给出系统将控制权转移到的起始的虚拟地址(入口点),即执行程序时第一条指令的地址，而在可重定位文件中，此字段为0。  
②多了一个.init节，其中定义了一个_init函数，用于可执行目标文件开始执行时的初始化工作。  
③少了两个.rel节，因为可执行目标文件中的指令和数据已被重定位，故可去掉用于重定位的节。  
④多了一个程序头表，也称段头表(segment header table),可执行文件中的节与虚拟空间中的存储段之间的映射关系

### 汉字字符的编码有哪三类?简述各类编码的作用，并分别列举一个实际的编码

汉字的编码分为输入码、内码和输出字形码。(2 分)输入码是用于汉字信息的输入,比如拼音码;(1分)内码是用于汉字信息在计算机内部的存储和处理，比如区位码:(1分)榆出字形码是用于汉字信息的输出显示,比如字模点阵码。(1分)

### 说明“进位”和“溢出”在概念和应用上有何不同?

常用于带符号数运算。

### 设某机器字长为32位,数值位31位,符号位1位。定点原码小数表示时,最大正数(十进制)为多少?最小负数(十进制)为多少?

定点原码小数表示时最大正数(十进制)；最小负数:

### 简述程序和指令的执行过程

程序的执行是周而复始执行一条一条指令的过程,每条指令的执行过程为:(1)根据PC取指令:将PC的内容作为地址访问主存,取出指令存入指令寄存器IR;(2)指令译码:对指令进行译码,确定操作类型和操作数地址;(3)PC增量:PC的内容加上当前指令的长度,计算下一条指令地址;(4)取操作数并执行:根据地址取出操作数,由ALU执行相应运算;(5)送结果:将运算结果送至主存或寄存器保存。程序执行前,需将程序起始地址存放在PC中,若为顺序型指令,下条指令地址为PC加当前指令长度;若为跳转型指令,下条指令地址为指令中指定的目标地址。

### 简述CISC和RISC指令系统的主要特点

(1)CISC风格指令系统:指令数目多,功能复杂;指令格式不规整,指令字长不固定;除Load/Store指令外,其他指令也可访存;通用寄存器数量较少。缺点是计算机结构复杂,研制周期和成本高,难以保证正确性,系统性能可能降低,复杂指令出现频率低,硬件资源浪费;(2)RISC风格指令系统:指令数目少;指令格式规整,采用定长指令字方式;只有Load/Store指令中的数据需要访存;采用大量通用寄存器。优点是CPU控制逻辑简化,芯片上可设置更多通用寄存器,指令可采用硬连线逻辑实现,适合指令流水技术,指令执行速度快,编译时间少,利于编译程序优化。


### 简述虚拟地址到物理地址的转换过程及快表(TLB)的作用。

① 转换过程:-虚拟地址分为虚拟页号和页内偏移;-根据页表基址寄存器找到页表起始地址,以虚拟页号为索引查找页表项;-若页表项装入位为1,取出物理页号,与页内偏移拼接形成物理地址;-若装入位为0,触发缺页异常,由操作系统将缺失页从外存调入主存并更新页表。  
② 快表作用:将页表中最活跃的页表项复制到高速缓存(快表)中,MMU先查询快表,命中则直接完成地址转换,未命中再访问主存中的页表,减少访存次数,加速地址转换过程。

计算机内部所有信息都采用二进制编码表示。(2分)但在计算机外部,大都采用八、十或十六进制表示形式。(2分)因此,计算机在数据输入后或输出前都必须实现这些进制数和二进制数之间的转换。(2分)

### 简述中断控制I/0方式的基本思想

当需要进行I /O 操作时,首先启动外设进行第一个数据的 I /O 操作,然后阻塞请求I /O的用户进程,并调度其他进程到 CPU上执行,期间外设在设备控制器的控制下工作。(2 分)外设完成 I /O 操作后,向 CPU 发送一个中断请求信号,CPU 检测到该信号后,则进行上下文切换,调出相应的中断服务程序执行。(2分)中断服务程序将启动后续数据的 I /O操作,然后返回到被打断的进程继续执行。(2分)


### 简述无符号数乘法和补码乘法的主要区别

(1)无符号数乘法:运算对象为无符号整数,乘积为两数绝对值之积,采用“判断-加法-右移”循环实现,n位无符号数乘法需n次循环,乘积为2n位,若仅取低n位则相当于取模2ⁿ;  
(2)补码乘法:运算对象为带符号整数(补码表示),可将符号位与数值位合在一起参与运算,直接得出补码表示的乘积,常用Booth乘法算法,通过“判断-加减-右移”循环实现,遇到连续1或0可跳过加法直接右移,效率较高,补码两位乘法(改进Booth算法)可将循环次数压缩为n/2,提高运算速度。


### 简述数组和指针在机器级表示中的联系与区别


(1)联系:两者均用于处理存储器中连续存放的一组数据,地址计算方法统一,数组元素的引用可通过指针实现,如a[i] = *(a+i) = *(ptr+i)(ptr为指向数组首元素的指针);  
(2)区别:数组名是常量,代表数组首地址,不能修改;指针是变量,可指向数组或数组中任意元素,可通过指针移动访问数组元素。机器级代码中,数组元素地址由首地址与下标计算得到,指针变量存储地址值,通过指针间接访问数据。数组分配在静态数据区或栈中,指针变量占用存储单元存放地址。

### 简述文件系统中VFS的主要数据结构及各自功能

VFS(虚拟文件系统)的主要数据结构包括:  
① 超级块:保存文件系统的通用元数据(如类型、版本),每个文件系统对应一个超级块,用于管理多个文件系统;  
② 目录项:保存文件名和对应inode号,目录本身是目录文件,其数据由目录项组成,用于路径解析,找到文件名对应的inode号;  
③inode:保存每个文件的元数据(如大小、所有者、访问权限、数据寻址信息),每个文件对应一个inode,系统中所有打开文件的inode组成inode表;  
④ 系统文件表:所有进程共享,每个表项对应一个打开的文件,保存inode指针、当前读/写位置、打开模式、引用计数等动态信息;  
⑤ 打开文件描述符表:每个进程独有,表项索引为文件描述符,表项指针指向系统文件表中的对应表项。

## 题目14

### 原题

分析C语言中“按值传递”和“按地址传递”参数的机器级实现差异。假设有函数void swap(int x, int y)和void swap_ptr(int *x, int *y),分别写出主函数调用这两个函数时的关键汇编指令片段(AT&T格式),并说明为何按值传递无法实现变量值交换。


(1)按值传递(swap函数)主函数调用汇编片段:

```gas
movl -4(%ebp), %eax    # 将变量a的值送入eax
movl %eax, 4(%esp)    #  a的值入栈(实参1)
movl -8(%ebp), %edx    # 将变量b的值送入edx
movl %edx, (%esp)     #  b的值入栈(实参2)
call swap             # 调用swap函数
```

(2)按地址传递(swap_ptr函数)主函数调用汇编片段:

```asm
leal -4(%ebp), %eax   #取变量a的地址送入eax
movl %eax, 4(%esp)    # a的地址入栈(实参1)
leal -8(%ebp), %edx   #取变量b的地址送入edx
movl %edx, (%esp)     # b的地址入栈(实参2)
call swap_ptr         #调用swap_ptr函数
```

(3)差异分析:

按值传递:栈中存放的是变量的副本,函数内部修改的是副本值,不影响原变量  
按地址传递:栈中存放的是变量的地址,函数内部通过间接寻址修改原变量的内存单元内容  
因此按值传递无法实现变量值交换,按地址传递可以


## 题目15

### 原题

某计算机系统采用虚拟存储器机制,页大小为4KB,虚拟地址为32位,物理地址为30位。假设某进程的虚拟地址0x8049120需转换为物理地址,页表项中该虚拟页对应的物理页号为0x102,且装入位为1。请设计地址转换过程,说明虚拟地址和物理地址的字段划分,并计算最终物理地址。


① 地址字段划分:  
虚拟地址32位,页内偏移占12位(4KB=2¹²B),虚拟页号占20位(32-12);  
物理地址30位,页内偏移与虚拟地址一致为12位,物理页号占18位(30-12)。

② 地址转换过程:  
1.提取虚拟地址的虚拟页号(高20位)和页内偏移(低12位);  
2.检查页表项装入位为1,说明该虚拟页已调入主存;  
3.取出页表项中的物理页号(0x102);  
4.将物理页号(18位)与页内偏移(12位)拼接,形成物理地址。

③ 具体计算:  
虚拟地址0x8049120的低12位页内偏移为0x120;  
物理页号0x102转换为18位二进制为00000000000100000010;  
拼接后物理地址为0x102120(十六进制)。

## 题目18

### 原题

某结构体定义如下:struct Data { char a; int b; short c; double d; },在IA-32/Linux平台(遵循i386 System V ABI对齐规则)下,分析该结构体的内存对齐方式,计算结构体总大小,并说明各成员的偏移量。如何调整成员顺序可使结构体占用空间最小?




(1)对齐规则:char无对齐要求,short按2字节对齐,int、float、double按4字节对齐

(2)原结构体成员偏移量与总大小:  
a:偏移0(1字节)  
b:偏移4(因需4字节对齐,插入3字节空)  
c:偏移8(因需2字节对齐,紧跟b之后)  
d:偏移12(因需4字节对齐,紧跟c之后)  
总大小:12 + 8 = 20字节(需为4的倍数,无尾部插空)

(3)优化成员顺序:struct Data { char a; short c; int b; double d; }

偏移量:a(0)、c(2)、b(4)、d(8)  
总大小:16字节(节省4字节)
